## 为什么要做这个东西

先说两句我常听到的话。

一句是求职者说的：投了几百份简历，一个回复都没有。

另一句是企业说的：花钱买了几百份简历，没一个能用。

两边都在骂。平台越做越大，钱越赚越多，招聘却越来越难。

技术、资本、数据都堆到顶了，两头还是不满意。那只能说明方向错了。

所以这个项目不是再做一个更快的中间商。我想把招聘这件事，拿回到真正需要工作的人、和真正需要人的企业手里。

革命从我做起，这次我自己来写。

## 现在的平台坏在哪

写代码之前，先把问题列清楚。这些不是我想出来的，是每天都在发生的事。

**求职者这边**

- 投递没有反馈。连一句「不合适」都等不到。
- 到处收费。看 HR 联系方式要 VIP，改简历要钱，内推要钱，测评要钱，还有培训贷。找工作的第一步，是被平台割一遍。
- 假岗位太多。挂着招聘的名字，实际是套方案、骗信息、拉人头、卖课程。
- 明着歧视。35 岁上限、性别偏好、卡第一学历、已婚未育直接筛掉。
- 搜索结果是买来的。谁充值多谁排前面，你看到的机会，是别人花钱买给你看的。
- 简历导不出来。数据存在平台里，想换个平台等于从头再来。

**企业这边，尤其是中小企业**

- 买了简历包，还是招不到人。包越来越贵，人越来越不对。
- 拼不过预算。大厂和猎头把钱砸下去，好候选人根本刷不到你的岗位。
- 没有专职 HR。小团队写 JD、筛简历、约面试，全是老板自己上。
- 正规企业被假岗位连累，求职者已经不敢信了。

**行业本身**

- 平台的商业模式建立在信息不对称上。两头越焦虑，平台越赚钱。这是结构性的矛盾，改不了。
- HR 背着加好友数量的 KPI，候选人被反复骚扰。
- 招聘是民生问题，却完全由商业公司掌握，既不透明，也不可审计。

说到底，现在的招聘平台卖的是焦虑，不是匹配。

## 要做的事

这七件事，是我们和现在平台最大的区别。

| 问题 | 我们怎么做 |
|---|---|
| 投了没回音 | 强制反馈。每份投递到期限必须给明确结果，不给平台介入 |
| 靠卖简历赚钱 | 求职者永久免费，简历数据永不售卖 |
| 假岗位、骗方案 | 企业实名，岗位审核，一键举报，黑名单共享 |
| 关键词匹配不准 | 做技能图谱，按能力撮合，不靠简历关键词 |
| 年龄性别学历歧视 | 盲筛。首轮隐藏年龄、性别、照片、第一学历 |
| 排序靠充值 | 排序算法开源，不付费也有完整曝光 |
| 数据被锁 | 一键导出，数据永远是用户的 |

另外三件平台不愿意做的事：

- 让中小企业被看见。用能力匹配代替预算竞价，好岗位不用靠充值。
- 每一次拒绝都给个理由。这不是施舍，是基本礼貌。
- 规则公开可监督。代码、算法、治理全在仓库里。

## 跟别的招聘平台有什么不同

因为它不属于任何一家公司。

- 非营利。不靠这个赚钱，不向求职者收费，不卖用户数据。
- 全开源。前后端、匹配算法、运营规则都在这里，谁都能审。
- 社区治理。重大决定公开讨论，规则由参与的人一起定。
- 不追日活。不做增长黑客，不制造焦虑，只想把匹配做对。

## 技术我来，策略靠你

我有技术，平台我来写。

但平台能不能活下去、能不能真的帮到人，光有代码不够。

我现在最缺的是策略，具体是这几块：

- 运营。公益平台怎么冷启动？第一批企业和求职者凭什么来？信任怎么建立？
- 法律。个人信息保护、数据合规、公益组织该怎么注册、平台责任边界在哪。
- 钱。非营利不等于不花钱，服务器、审核、运营都要钱。在不违背底线的前提下怎么活下来？
- 产品。一个反商业逻辑的东西，怎么才能好用、有人愿意用？
- 社区。开源社区怎么管，争议怎么裁，规则怎么迭代。
- 行业。你是 HR、猎头、求职者还是创业者，你踩过的坑，就是我们下一个要修的问题。

技术我扛，方向我们一起定。

有想法的话，直接去 [Discussions](https://github.com/InfernalAzazel/people-hire/discussions) 开帖，或者提个 Issue 把你的方案写出来。运营模式现在还是白纸，第一条规则还没写。

## 运营模式

喊口号容易，活下去难。所以这一块我不藏，摊开讲。

先定四条不能动的：

1. 求职者永久免费，不做任何「付费才能被看见」的功能。
2. 不卖、不换用户的简历和个人数据。
3. 算法和排序规则开源可审计，付钱不影响任何人的曝光。
4. 财务公开，收支定期公示。

剩下这些我还没答案，等你们来答：

- 成本靠什么覆盖？捐赠、基金会，还是企业端的合规服务？
- 审核团队怎么组织？志愿者，还是少量专职？
- 治理结构怎么设计？理事会、社区投票，怎么防止被少数人控制？
- 「不收费」和「活下去」之间，真正的平衡点在哪？

这些不是我一个人能拍板的。

## 路线图

| 阶段 | 做什么 | 状态 |
|---|---|---|
| Phase 0 | 开源仓库，公开理念，找第一批共建者 | 进行中 |
| Phase 1 | 简历管理和数据导出、真实岗位库、强制反馈 MVP | 规划中 |
| Phase 2 | 企业实名、岗位审核、盲筛、中小企业扶持 | 规划中 |
| Phase 3 | 技能图谱和开源匹配算法，公开评测 | 规划中 |
| Phase 4 | 社区治理规则、财务公开、非营利实体 | 规划中 |

路线图会随时改。每一条都可以被质疑，也可以被推翻重写。

## 怎么支持

Star 就是投票。

我想知道今天还有多少人愿意支持一个不一样的招聘平台。

- 点 Star。让更多人看到，也让我知道有多少人在做同一件事。
- 提 Issue。说你遇到的招聘问题，或者指出我哪里想错了。
- 来 Discussions。贡献运营策略、法律意见、财务方案。
- 转给需要的人。那些正在被招聘平台折腾的求职者和中小企业主。

现在不用捐钱。先表个态就够了：你希望招聘平台变成什么样。

## 一起做

代码、文案、设计、法律意见都欢迎。哪怕只是一句「这个方向对」，也算。

1. 看 [CONTRIBUTING.md](./CONTRIBUTING.md)
2. 去 [Issues](https://github.com/InfernalAzazel/people-hire/issues) 认领任务，或者提新想法
3. 去 [Discussions](https://github.com/InfernalAzazel/people-hire/discussions) 聊策略
4. 提 Pull Request

这里不看学历、年龄、出身，只看你想不想把这件事做对。这一点，也正好是我们想对招聘行业做的事。

## 最后

「如果招聘平台不能解决问题，那它就不该存在。」

这句话不是骂谁。工具存在的意义是解决问题，工具开始制造问题的时候，就该有人重做一个。

我们不一定一次做对，肯定也会犯错。但至少这一次，规则是公开的，数据是你的，平台是大家的。

革命从我做起，就从这份 README 开始。
